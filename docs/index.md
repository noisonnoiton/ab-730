# AB-730 AI Business Professional

Microsoft 365 Copilot과 agent를 사용해 일상 업무 생산성을 높이고 business outcome을 만드는 실무자를 위한 시험 대비 자료입니다.

!!! info "시험 대상"
    코드를 작성하거나 AI app을 개발하는 역할이 아닙니다. Outlook, Word, Teams, PowerPoint, Excel 등 Microsoft 365 app에서 생성형 AI를 안전하게 활용하고, 효과적인 prompt와 agent를 관리하며, 문서와 meeting 결과를 만드는 능력을 평가합니다.

## 학습 영역

| Domain | 비중 | 핵심 질문 |
| --- | --- | --- |
| [생성형 AI 기본 이해](domain1-generative-ai-fundamentals/index.md) | 25-30% | Copilot은 어떤 context를 사용하며 어떻게 조직 data를 보호하는가? |
| [Prompt와 conversation 관리](domain2-prompts-conversations/index.md) | 35-40% | 효과적인 prompt, chat, notebook, agent를 어떻게 만들고 관리하는가? |
| [Business content 작성 및 분석](domain3-business-content/index.md) | 25-30% | 문서, communication, meeting, collaboration 결과를 어떻게 만드는가? |

## 학습 방법

- 기능 이름만 외우기보다 **업무 목표 -> 적절한 context -> Copilot experience -> 검증** 순서로 판단합니다.
- 실습할 때는 prompt의 목표, context, source, output 형식을 바꾸며 결과 차이를 확인합니다.
- 생성 결과는 초안으로 취급하고 citation과 원본을 확인하며 sensitive data의 permission을 검토합니다.
- [시험 정보](exam/overview.md)의 objective checklist로 학습 누락을 점검합니다.

!!! warning "최신 기능"
    Microsoft 365 Copilot 기능과 UI는 자주 변경됩니다. 이 문서는 2026년 7월 22일 skills measured를 기준으로 하며, 실제 기능은 Microsoft Learn과 tenant 환경에서 다시 확인해야 합니다.
