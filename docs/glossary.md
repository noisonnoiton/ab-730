# 용어집

| 용어 | 설명 |
| --- | --- |
| Agent | 특정 역할을 위해 knowledge, instruction, capability를 구성한 AI experience |
| Agent Store | 사용 가능한 agent를 찾고 선택하는 catalog |
| Capability | Agent가 사용할 수 있는 action 또는 tool 기능 |
| Citation | Response의 주장과 연결된 source reference |
| Context | Response 생성에 사용되는 현재 대화, app, file, 업무 data 등의 정보 |
| Copilot Pages | Copilot response를 editable content로 전환해 공동 작업하는 surface |
| Fabrication | Model이 근거 없는 내용을 그럴듯하게 생성하는 현상 |
| Grounding | Model response를 특정 source나 업무 data에 연결하는 방식 |
| Human review | AI output을 사람이 검증하고 승인하는 통제 |
| Instruction | Copilot이나 agent의 역할과 response behavior를 지정하는 지침 |
| Knowledge | Agent response의 근거로 구성한 source 집합 |
| Large language model | 대규모 language data에서 pattern을 학습해 text를 처리하고 생성하는 model |
| Memory | Preference나 context를 이후 interaction에 활용하는 기능 |
| Microsoft Graph | Microsoft 365의 user, file, mail, calendar 등 업무 context를 연결하는 data layer |
| Notebook | 관련 conversation과 reference를 모아 지속적으로 분석하는 workspace |
| Over-reliance | AI output을 충분한 검증 없이 신뢰하고 사용하는 risk |
| Prompt | AI에 목표, context, source, 기대 결과를 전달하는 입력 |
| Prompt injection | 악의적인 content가 원래 instruction을 무시하도록 유도하는 공격 |
| Responsible AI | AI를 공정성, 신뢰성과 안전, privacy와 security, 포용성, 투명성, 책임성 원칙에 따라 사용하는 접근 |
| Sensitive data | 개인정보, 재무 정보, 계약 정보 등 보호와 access control이 필요한 data |
| Suggested prompt | Agent 사용자가 대표 작업을 쉽게 시작하도록 제공하는 prompt 예시 |
| Work data | Microsoft 365에 저장되고 사용자의 permission으로 접근하는 조직 data |

!!! note "용어 사용"
    Microsoft 365 Copilot의 UI와 기능 명칭은 release에 따라 바뀔 수 있습니다. 시험 준비 시 [공식 study guide](https://learn.microsoft.com/en-us/credentials/certifications/resources/study-guides/ab-730)의 최신 terminology를 우선합니다.
