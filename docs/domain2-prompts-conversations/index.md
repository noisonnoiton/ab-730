# Domain 2 - Prompt와 conversation 관리

- **비중 35-40%**
- 가장 큰 시험 영역으로 prompt 작성과 저장, 예약, 공유, conversation 관리, agent 작성과 공유를 다룹니다.

## 구성

| 문서 | 내용 |
| --- | --- |
| [Prompt 작성과 관리](01-prompts.md) | 효과적인 prompt, resource 참조, 저장, 예약, 공유 |
| [Conversation 관리](02-conversations.md) | 이전 chat 검색, 이름 변경, 삭제, notebook 추가 |
| [Copilot agent 관리](03-agents.md) | Agent Store, template, knowledge, instruction, capability, 공유 |

## 핵심 구분

| 필요 | 선택 |
| --- | --- |
| 한 번 실행할 명확한 요청 | Prompt 작성 |
| 반복 실행할 검증된 요청 | Prompt 저장 또는 예약 |
| 관련 대화와 source를 모아 지속적으로 분석 | Notebook |
| 특정 업무를 위한 knowledge와 behavior 재사용 | Agent |

!!! abstract "요약"
    좋은 prompt는 목표, context, source, 기대 결과를 분명히 합니다. 반복성이 커질수록 저장, 예약, 공유를 사용하고, 안정된 instruction과 knowledge가 필요하면 agent로 발전시킵니다.
