## 생성형 AI 기본 이해

### Microsoft 365 experience 전반의 생성형 AI capability

- Copilot이 조직 정보를 private하고 secure하게 유지하는 방식 이해
- 업무 file, web data, 현재 app과 같은 context가 response에 미치는 영향 이해
- chat experience와 agent experience의 차이 이해
- 직접 agent를 만들어야 하는 use case 이해
- Microsoft 365 app별 Copilot feature와 capability 차이 이해

### Responsible AI와 data protection practice

- fabrication, prompt injection, over-reliance 등 일반적인 risk 식별
- citation 확인과 human review 등 작업에 맞는 verification step 선택
- sensitive data risk 식별 및 완화
- data protection이 prompt result를 제한하는 방식 이해

## Prompt와 conversation 관리

### Microsoft 365 Copilot prompt 작성 및 관리

- 효과적인 prompt 작성 방식 이해
- prompt에서 참조할 적절한 resource 선택
- prompt 저장, 예약, 공유

### Microsoft 365 Copilot conversation 관리

- 이전 conversation 검색
- chat 삭제 및 이름 변경
- conversation을 notebook에 추가

### Microsoft 365 Copilot agent 작성 및 관리

- Agent Store 사용과 새 agent 작성 시점 구분
- template을 사용한 agent 작성
- knowledge가 있는 agent 구성
- instruction, capability, suggested prompt와 같은 agent setting 구성
- team member와 agent 공유

## Business content 작성 및 분석

### Business document와 communication 작성

- prompt에서 새 document 작성
- 기존 document에서 document 생성
- document 기반 management summary 생성
- Microsoft 365 app 사이에서 data와 insight 이동

### Meeting과 collaboration 관리

- meeting에서 Microsoft 365 Copilot을 사용하는 방식 설명
- collaboration에 Copilot Pages를 사용하는 방식 설명
- Copilot이 memory와 instruction을 사용하는 방식 설명
